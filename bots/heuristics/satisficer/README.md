# Satisficer

The active policy ranks completed rewards, then useful income with a survival
reserve, then shorter cycles after congestion. A progress lease retains an
incumbent while best travel distance or remaining camp HP improves. Banking and
bag-sensitive retreat remain separate decisions.

`SATISFICER_ROUTE_REFUSAL=1` selects the repaired local executor. Explicit `0`
preserves the established executable. The repair remembers an actual blocked-goal or bounded route-field refusal
and applies the existing short source quarantine after the field has spent its
fuel. A return before the movement fuel floor is incomplete work and does not
invalidate the source. No safety floor, visibility rule or policy rank changes.

monolith gate blocked northern gold that static topology admitted. The field
refused the route, but the old post-field 45K fuel check discarded that result.

3 clears / 160 gold to 43 / 3,012; A changed from 44 / 2,868 to 46 / 3,806.
The blocked altar still prevents banking there.
