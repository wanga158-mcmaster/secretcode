# Official reference snapshots

The current Cambridge Battlecode Autumn 2026 bundle is pinned in
[current-version.json](current-version.json): CLI/SDK **3.0.5**, engine **1.0.3**, replay format
**0.0.3** and **40 official maps**, with exact file hashes (`arena env` checks every pinned file and the pool maps). The map
pool was checked again using an isolated official CLI 3.0.5 `init` on 22 October: all 40
payloads and the filename index match the preceding bundle. The earlier 22 October refresh
added 00gem_fields, 00gemfight, 00great_wall, 00lost_world and 00road_of_riches.

- [GameRules.md](GameRules.md) and [BotAPICpp.md](BotAPICpp.md): the official handbook
  **Download for LLM** exports from [Agents.md](https://2026a.battlecode.co.uk/game/docs/agents).
  Both were regenerated from the current official website's export functions on 22 October.
  The C++ export is unchanged; the rules clarify camp timer ordering and sleeping conditions.
- [distribution.json](distribution.json): the official
  [distribution API](https://2026a.battlecode.co.uk/api/v1/distribution) snapshot (CLI provenance).
- [Map pool](../../maps/pool.json): the official [pool API](https://2026a.battlecode.co.uk/api/v1/maps/pool).
  `.cambc/map-pool.json` maps pool UUIDs to the actual filenames (`00reverse_spiral` is the file
  `00reverse-spiral.map26a`); arena uses the file stems as map names.
- [runtime-catalog.json](runtime-catalog.json): settings, 13 champions, six camp types and 42
  items queried from the official 1.0.3 editor engine with SDK ABI assertions. Their gameplay
  values match the previous catalog; its map metadata now covers all 40 official maps.
- [Map geometry](../../maps/geometry.json): terrain, spawns and physical camp groups of all 40 maps,
  regenerated by `node tools/export-game-geometry.mjs`.
- [engine-identity.json](engine-identity.json): the CLI's statistics build identifier combined
  with the editor's `Version()` export.
- [updates/](updates/): the historical 1.0.2 website review with patch notes and public review
  data. The public patch index still listed 1.0.2 as its latest entry on 22 October; no 1.0.3
  patch notes were published there at the time of this upgrade.
- `../../sdk/` and `../../cmake/`: the exact official CLI 3.0.5 `init` outputs. Never edit them;
  keep third-party licenses and notices.

The handbook is live and its prose can lag the engine: query settings from the SDK rather than
copying constants. Current corrections are listed in [rules notes](../rules-notes.md). Upgrade
the CLI, SDK, rules and maps together, then refresh the geometry. `tools/runtime-catalog/`
contains the reusable catalog capture (`capture.mjs`, `abi.cpp`):
`node tools/runtime-catalog/capture.mjs --out .cache/runtime-catalog/FRESH_DIR` reads current
manifest pins; explicit engine, project and compiler options support isolated upgrade staging.

The 3.0.5 SDK changes seven files: debug drawings now persist until their owning champion's
next turn, and Rust adds checked byte-casting traits and pinned dependency re-exports. CMake,
starter templates, licenses and the CLI-managed Clang 22.1.0 / WASI SDK 33 are unchanged.
Replaced vendor files are preserved under `D:\files\battlecode-removed\` at their original
relative paths. Historical replay fixtures and decoder profiles remain available beside a
fresh 3.0.5 fixture; engine identities must not be mixed when interpreting old evidence.

Replay decoding, the loopback viewer and full-world prefix comparison accept the verified
1.0.3 profile while retaining historical 1.0.1/1.0.2 decoders where supported. Four full local
smoke games (fundamentals versus starter, 00collision and 00gem_fields, both sides) completed
without faults, fuel exhaustion, error logs or stalls; this is integration coverage, not an
all-map bot health or strength claim.

Upgrade validation: all 14 replay/map/arena tool test files pass, including 44 compiled-runner
tests. `arena build all` built 205/205 selected bots. All checks from 13 suite runners pass,
with a focused retry of events'
[`altar_minimum_maps.py`](../../bots/events/tests/altar_minimum_maps.py) after its owner
replaced old version pins with manifest checks. That pure-cache fixture passes on all 40
maps, 2,741 possible member anchors and 159,528 cases; it makes no native fuel claim.
Historical population panels and executable manifests also retain their original bundle
bindings: current-engine use requires freshly pinned evidence, rather than rewriting old records.
